# Концепция музыкального плеера для macOS в духе Winamp

## Идея

Создать музыкальный плеер для macOS, который по возможностям и характеру
ближе к классическому Winamp, а не к минималистичному QuickTime Player.

Главная мысль: **это полноценный музыкальный центр, который пользователь
может настроить под себя**, а не просто окно с кнопкой Play.

## Чем ориентироваться на Winamp

-   **Музыка --- основной сценарий.** Интерфейс и функции должны быть
    заточены прежде всего под прослушивание музыки.
-   **Эквалайзер.** Предусмотреть эквалайзер с настройкой частот и
    готовыми пресетами.
-   **Плейлисты.** Удобное создание, редактирование, сортировка и
    переключение плейлистов.
-   **Медиатека.** Работа с локальной музыкальной коллекцией.
-   **Кастомизация.** Поддержка тем оформления или скинов, чтобы
    пользователь мог менять внешний вид плеера.
-   **Визуализации.** Добавить музыкальные визуализации; ориентир по
    атмосфере --- MilkDrop из Winamp.
-   **Форматы.** Поддерживать распространённые аудиоформаты и корректно
    обрабатывать неподдерживаемые файлы.

## Позиционирование относительно QuickTime Player

QuickTime Player --- минималистичный универсальный проигрыватель, в
котором мало возможностей для настройки музыкального опыта.

Новый плеер должен выигрывать за счёт: - музыкальной специализации; -
развитого управления плейлистами и медиатекой; - эквалайзера и звуковых
настроек; - визуализаций; - персонализации интерфейса.

## Ожидаемый результат

Приложение для macOS, которое сочетает удобство современного
Mac-приложения с функциональностью и индивидуальностью классического
Winamp.

**Ключевой принцип:** функциональность, настройка под пользователя и
удовольствие от прослушивания важнее предельной минималистичности
интерфейса.

## Указание для Codex

Используй этот документ как краткое продуктовое направление при
проектировании и реализации приложения. Не воспринимай сравнение с
QuickTime как требование копировать его интерфейс. В качестве главного
ориентира по возможностям и духу используй Winamp.
